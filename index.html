  • Activate the plugin with the issued license key.

Installation Guide

  1. Download the Curve Factory build after your free license is issued.
  2. Extract the downloaded zip file.
  3. Copy the extracted CurveFactory folder.
  4. Paste it into your Adobe CEP extensions folder.
  5. Windows path: C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\
  6. macOS path: ~/Library/Application Support/Adobe/CEP/extensions/
  7. Restart After Effects.
  8. Open Window > Extensions > Curve Factory.
  9. Enter the license key issued on this page and click Activate.

Updating Curve Factory

  1. Close After Effects before updating.
  2. Download the newer Curve Factory build.
  3. Extract the new zip.
  4. Replace the old CurveFactory extension files with the new files.
  5. Keep the same extension folder name and manifest IDs.
  6. Do not reset local activation unless support asks you to do so.
  7. Open After Effects again and launch Curve Factory.

Saved presets, library settings, local device ID, and activation are stored by the CEP panel. They remain available across updates when the extension identity stays the same.

Troubleshooting

  • If the extension does not appear, confirm the folder is inside the CEP extensions directory.
  • If activation asks again after an update, confirm the extension ID was not changed in the manifest.
  • If the download fails, check that the build zip exists inside the website dist folder.
  • If Google sign-in fails, confirm this GitHub Pages domain is added in Firebase authorized domains.
